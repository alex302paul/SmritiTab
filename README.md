# SmritiTab — Wallpaper-First Redesign (Chrome MV3 Extension)

## Install in Chrome
1. Unzip SmritiTab-Redesign-Extension.zip (or use this folder directly).
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select this folder.
4. Open a new tab to use SmritiTab.

## Preserved compatibility
- Storage namespace `smrititab:v1` (chrome.storage.local + localStorage fallback)
- Quick Links categories `cat_work` / `cat_daily` and all user links & edits
- Service worker: selection context menu + `open-search` / `toggle-focus-mode` commands
